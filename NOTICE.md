# Flyto2 Runtime attribution

Flyto2 Runtime is an independent fork of the DevSpace project originally created by Waishnav:

- Upstream repository: https://github.com/Waishnav/devspace
- Fork repository: https://github.com/flytohub/flyto-runtime
- Upstream license: MIT

The original MIT copyright and permission notice are preserved unchanged in `LICENSE`.

Flyto2 Runtime is independently maintained by the Flyto2 project. It is not affiliated with, sponsored by, or endorsed by the upstream DevSpace author.

The fork intentionally preserves a compatibility path for existing DevSpace users while adding source-native Flyto2 capabilities such as durable operation replay, runtime capability manifests, and an optional Flyto2 Cloud execution bridge. The standalone MCP/runtime path does not require Flyto2 Cloud.
